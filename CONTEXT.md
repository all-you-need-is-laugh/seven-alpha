# Seven Alpha

A personal task-management app. A single collection of Tasks, organized into Lists and (later) viewed through many lenses (Eisenhower matrix, ICE prioritization, planners, roadmap).

## Language

**Task**:
The central entity — a single unit of work the user tracks and marks complete.
_Avoid_: Item, todo, card, ticket

**List**:
A named container that holds Tasks. Each Task belongs to exactly one List at a time; moving a Task changes which List holds it.
_Avoid_: Folder, bucket, column, board, tag, label
